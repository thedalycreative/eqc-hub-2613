Get to know Git

Version control is how real teams ship. Start at the top and work down — install it, learn the handful of commands you'll use every day, then practise.

Git & GitHub

Save your work, undo mistakes, and share code without emailing zip files.

1 · Install & set up

  • Install GitMac, Windows and Linux downloads
  • GitHub DesktopThe easy way in — no terminal needed
  • Create a GitHub accountUse your real name — it becomes your portfolio
  • Set up GitName, email and first-time config

2 · Learn the basics

  • GitHub Hello WorldThe official 15-minute first repo
  • W3Schools Git TutorialShort lessons, same style as class
  • Pro Git (free book)The reference — read chapters 1 to 3
  • Git & GitHub crash coursefreeCodeCamp, one sitting

3 · Practise & troubleshoot

  • Learn Git BranchingVisual and game-like — the best way to make it click
  • Oh Sh!t, Git!?Fixes for when you've broken something
  • GitHub Git Cheat SheetOne-page PDF — print it
  • Class reposEvery build we do in class

The commands you'll actually use

git clone <url>Copy a repo to your machine
git statusWhat have I changed?
git add .Stage your changes
git commit -m "..."Save a snapshot with a message
git pushSend it up to GitHub
git pullGet the latest changes down
