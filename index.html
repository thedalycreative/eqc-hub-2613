S02-A01 · Bootstrap Clone (aka Build a Bootstrap Website)

Current assignment

Everything for the current assignment in one place: clone the Forbidden Forest site with Bootstrap 5.

The build

  • Original site — the one we're cloning
  • Class repo — full clone + README teardown
  • Flexbox exercise repo (the warm-up)

Requirements

  • Rebuild the layout with Bootstrap 5 via CDN — no npm, no build step
  • Minimum 5 files: pages + stylesheet + images folder
  • JavaScript only for the carousel
  • No inline styles — custom CSS lives in your stylesheet
  • Alt text on every image; semantic tags; QA checklist before you submit
