## What we covered
- **Git, finally sorted:** on Windows, **GitHub Desktop** is the reliable path — Norton antivirus blocks the CLI/SSH route. Collaborators added by hand where the clone was denied
- 2FA gotcha: the login wants the **terminal-generated code**, not the 6-digit authenticator one
- [roadmap.sh](https://roadmap.sh) — walked through as a developer learning map. Save it
- **Submitting the clone:** zip your local project folder and upload to Study Hub → **Subject 2 → Activities → Build a Bootstrap Website**. You upload the code, not a GitHub link
- **Before you zip:** delete the `README` and `.gitignore` files
- A README is **optional / bonus** — not a requirement. Want the extra credit? [Best-README-Template](https://github.com/othneildrew/Best-README-Template) is a good start
- Expect minor feedback in 1–2 weeks. That's the normal process — don't be discouraged
- **Subject 1, Activity 2 — ICT Support:** client "Katie" (a videographer) can't be found on Google. The problem is SEO, and it lives in the `<head>` metadata
- The fix: rewrite `title`, `description`, `keywords` and `author` — the original had placeholder junk ("Bruce Wayne", "hi I am a keyword")
- **Match the metadata to the visible page.** The description echoing the homepage's "capturing moments that last a lifetime" is a consistency signal search engines reward
- `author` is *your* company (the contractor), not the client. Copy the same metadata across every page — consistent is fine and recommended
