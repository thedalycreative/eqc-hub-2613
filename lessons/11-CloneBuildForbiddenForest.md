**Date:** Mon 20 Jul 2026 · **Subject:** S2 (Front End Web Dev)

## Focus
The clone got the green light — we're rebuilding the Harry Potter: A Forbidden Forest Experience site on Bootstrap 5. Tim built it live in class; all the code is on GitHub to pull apart and reuse.

## What we covered
- **Capturing the target:** save the live page from Chrome as "Webpage, Complete"
- **Asset discipline:** every image and font organised into a numbered `assets/` tree
- **Sampling the brand:** ice `#a3e6ef` · gold `#bd9e63` · parchment `#e5dbc1` on near-black navy
- **Bootstrap rebuild:** fixed navbar + dropdown, hero video-over-poster stack, starfield parallax, `row-cols-*` grids, press carousel, treeline footer
- **The showpiece:** pure-CSS fireflies — `@keyframes` drift + flash, zero JavaScript
- Rules of the build: CDN only · no inline styles · alt text on everything

## Assignment: S02-A01 · Bootstrap Clone
Rebuild the Forbidden Forest site's layout with Bootstrap 5.

**Rules:**
- Bootstrap 5 **via CDN** — no npm, no build step
- Minimum **5 files**: pages + stylesheet + images folder
- JavaScript only for the **carousel** (Bootstrap's bundle does it)
- No inline styles — custom CSS lives in your stylesheet
- Alt text on every image; semantic tags; QA checklist before you submit

**Walkthrough:** [Clone a Bootstrap site in 5 minutes](../references/clone-a-site.md)
