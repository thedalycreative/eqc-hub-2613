Part 1 — Evaluate Current Strategic Plan

Q1 · Summarise the organisation's current strategic plan (list the main points).

ABC Solutions aims to become an innovative IT industry leader by delivering cutting-edge digital solutions. Their core objectives focus on achieving market leadership, driving digital transformation, and ensuring data security and customer satisfaction.

Q2 · How does the strategic plan align with the current industry environment and organisational objectives?

The strategic plan correctly focuses on innovation and security to match today's highly competitive tech industry. However, the company cannot achieve these objectives because its current website infrastructure is too outdated to reflect modern industry standards.

Q3 · What software systems are used?

The website's front-end is built using legacy HTML 4 and CSS 2 software technologies.

Q4 · What data management systems are used?

The organisation uses the MySQL relational database management system to handle and store its website data.

Q5 · What website hosting platform is used?

The entire website system is currently hosted on a rigid dedicated physical server.

Q6 · Compare the strategic plan with the current state of the ICT systems — list any gaps or improvement opportunities.

The primary gap is an ancient, non-responsive website that fails to showcase innovation and lacks mobile usability. Additionally, the rigid dedicated server hosting limits the company's ability to scale quickly and exposes legacy databases to modern security vulnerabilities.

Q7 · Write out a proposal for a change/changes to the organisation's ICT systems.

I propose rebuilding the website frontend using modern HTML5 and CSS3 to ensure it is fully mobile-responsive and secure. Furthermore, the legacy MySQL database should be safely migrated to a scalable, managed cloud hosting platform like AWS or Google Cloud.

Part 2 — Evaluate Effects of Changes

Q8 · Do the proposed ICT changes support what the organisation wants to achieve in the long run?

Yes, a modern, cloud-hosted website directly supports their long-term goals of looking innovative and attracting higher-paying software clients. It also builds market trust by upgrading the baseline security of their data infrastructure.

Q9 · What will the potential impacts be of implementing the proposed changes? (positive or negative)

Positives include faster page load speeds, an enhanced brand image, and robust user data security. Negatives include the initial financial cost of development and potential short-term network downtime during the live server migration.

Q10 · How will the proposed ICT changes contribute to helping the organisation reach its goals?

The changes will turn their website into a fast, mobile-friendly marketing tool that explicitly proves their technical expertise to prospective clients. This directly drives lead generation, increases corporate revenue, and positions ABC Solutions as a digital leader.

Q11 · Evaluate the difficulty of implementing the proposed changes. What difficulties could you encounter? List 2.

The overall implementation difficulty is moderate, with a primary risk of data corruption when migrating the old MySQL database schemas to the cloud. Second, internal staff will face a learning curve and require training to confidently manage the new cloud platform interface.

Action Plan

Q12 · Priority steps that need to occur (list as many as is relevant).

First, we must audit the existing database content, research modern hosting vendors, and present wireframes to management. Following approval, the technical team needs to code the new frontend, test data migration in a private staging environment, upskill staff, and execute the live launch.

Q13 · Write a proposed schedule that they will occur in.

  • Assessment Phase (2 weeks): Audit legacy assets and document system prerequisites.
  • Planning Phase (3 weeks): Design mobile-responsive wireframes and evaluate cloud infrastructure providers.
  • Testing Phase (2 weeks): Migrate legacy data to a private staging server and run rigorous security penetration checks.

Trainer tip: pad every phase — propose 3 weeks when you expect 2. Under-promise, over-deliver.

Q14 · Show your answers for Part 2 to your supervisor and gather feedback.

My supervisor reviewed and approved the proposal, providing feedback that we must complete all testing and training on a private staging server before altering the live public domain.

Q15 · Are there any industry best practices or regulatory requirements that need to be adhered to?

We must comply with the Australian Privacy Principles (APPs) to protect client data inputs from unauthorized breaches. The new user interface must also adhere to WCAG 2.1 guidelines to guarantee digital accessibility for all users.

Heads-up from class: new Australian privacy legislation lands around 6 December this year — and WCAG 2.1 gets its own class on Monday.

Q16 · What are the key performance indicators (KPIs) or metrics aimed to be achieved?

The project aims to achieve a baseline website page loading speed of under 2 seconds and secure a 25% increase in client inquiries through the site within 60 days of launch.

Q17 · How will the schedule be monitored throughout the implementation process?

Progress will be tracked visually using a digital Kanban board on Trello, combined with short, weekly team stand-up meetings to rapidly address any project bottlenecks. (Notion, monday.com, or GitHub Projects work just as well — pick one and stick with it.)

Q18 · Estimate what costs may be associated with the proposed changes.

The total capital investment is estimated at $14,500 AUD, covering $12,500 for professional UX/UI design and responsive database development, $1,200 per year for managed cloud infrastructure, and $800 for internal staff training.

Based on current Perth grocery pricing of $4.90 per kilogram, this entire technical overhaul equates to investing exactly 2,959 kilograms of fresh loose bananas (or approximately 17,407 individual bananas). 🍌

About that number

The assessment's placeholder figure is $3,600 — nowhere near a realistic quote for a rebuild + migration + training in the current market. We used ~$14,500 in class as a defensible real-world estimate. Whichever figure you use, show the breakdown.
