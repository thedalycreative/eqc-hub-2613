2.01 · Bootstrap Clone

Rebuild the Harry Potter: A Forbidden Forest Experience site's layout using Bootstrap 5. Same skills you're learning in class, applied to a live target.

The rules

  • Bootstrap 5 via CDN — no npm, no build step
  • Minimum 5 files: pages + stylesheet + images folder
  • JavaScript only for the carousel (Bootstrap's bundle does it)
  • No inline styles — custom CSS lives in your stylesheet
  • Alt text on every image; semantic tags; QA checklist before you submit

Deliverable

Zip your local project folder (delete README and .gitignore first) and upload to Study Hub → Subject 2 → Activities → Build a Bootstrap Website. You upload the code, not a GitHub link.

The class-built reference version lives in the repo below. Use it to see how Tim assembled the pieces — don't just copy it wholesale.
