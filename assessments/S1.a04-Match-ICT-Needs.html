S1.a04 · Match ICT Needs

Done · Class 8 · Case study: ABC Solutions.

The brief

ABC Solutions runs an HTML4/CSS2 site with no mobile support, no accessibility, and legacy hosting. Diagnose the gaps against modern standards, propose an HTML5/CSS3 rebuild with cloud hosting, and cost the migration realistically.

Tasks

  1. List every gap between the current site and modern standards.
  2. Propose an HTML5 / CSS3 rebuild, including mobile responsiveness.
  3. Recommend hosting (cloud) and briefly justify.
  4. Reference Australian Privacy Principles and WCAG 2.1 compliance where relevant.
  5. Cost the migration end-to-end (class model came in around $14,500).
  6. Argue why an AI agent can do most of the HTML4 → HTML5 translation without a full rebuild.
  7. Answer all 18 questions in the activity brief.
