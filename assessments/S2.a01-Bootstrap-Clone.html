S2.a01 · Bootstrap Clone

Done · Class 11 · Rebuild the Forbidden Forest site.

The brief

Rebuild the layout of the Harry Potter: A Forbidden Forest Experience site using Bootstrap 5. This isn't about copying pixels — it's about proving you can look at a live page, identify the components, and reassemble them with the Bootstrap grid.

The rules

  1. Bootstrap 5 via CDN — no npm, no build step.
  2. Minimum 5 files: HTML pages + one stylesheet + an images folder.
  3. JavaScript only for the carousel (Bootstrap's bundle handles it).
  4. No inline styles — custom CSS lives in your stylesheet.
  5. Alt text on every image; semantic tags; QA checklist before you submit.

Model answers

What "done" looks like

  • Fixed navbar with a working dropdown.
  • Hero with video-over-poster stack (the video is a background, the poster is the fallback).
  • Starfield parallax on scroll.
  • A row-cols-* grid of experience cards.
  • Press carousel that scrolls through logos/quotes.
  • Treeline footer with contact + socials.
  • Pure-CSS fireflies as the finale (@keyframes drift + flash, zero JavaScript).

Boilerplate every page shares

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Forbidden Forest — A Harry Potter Experience</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <!-- your components here -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
