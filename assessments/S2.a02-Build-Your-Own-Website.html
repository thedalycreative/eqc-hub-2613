Subject 2 · Front End Web Dev

S2.a02 · Build Your Own Website

Not yet run in class · Kicks off Class 15 · Runs across 10 classes.

The brief

Same Bootstrap skills as the clone — but this time you pick the subject, and every design decision is yours. About 4 pages, real content, real images, portfolio-ready.

The rules

  1. A real subject: yourself, a real business, or a club you belong to.
  2. ~4 pages with a working nav on every one.
  3. Bootstrap 5 via CDN, your own style.css loaded after it.
  4. Real content and real images — no lorem ipsum in a submission.
  5. Validate, run WAVE, and test on an actual phone before you submit.

Model plan (spread across classes 15–24)

Reword the plan for your own site. This is a template of the process, not the content.

Week 1 · Concept & sitemap

  • One-sentence "who this is for" statement pinned to the top of your notes.
  • Sitemap on paper: 4 boxes, arrows between them, what each page has to do.
  • Colour palette (Coolors) and typography pair (Google Fonts) chosen before you code.

Week 2 · Wireframe & skeleton

  • Low-fi wireframes for every page — Excalidraw is fine.
  • HTML shell for every page: nav + section boxes + placeholder text. No styling yet.
  • Every image tag has an alt attribute from the moment it's added — retrofitting is worse.

Week 3 · Build

  • Fill in each page top-to-bottom. Real copy, real images.
  • Check every breakpoint: xs · sm · md · lg · xl.
  • Photos from Unsplash / Pexels if you don't own the rights.

Week 4 · Review & polish

  • W3C HTML/CSS validators — clean pass on every page.
  • WAVE accessibility scan — zero errors, contrast alerts explained.
  • PageSpeed Insights on mobile and desktop.
  • Favicon, meta description, OpenGraph tags — the little polish signals.
  • Test on an actual phone. Not DevTools mobile mode. An actual phone.

What the assessor is looking for

  • The nav works on every page.
  • Every image has an alt.
  • The site tells you what it's for within 5 seconds of landing.
  • The contact / booking / call-to-action path works end-to-end.
  • It doesn't break on a 375px-wide phone.
