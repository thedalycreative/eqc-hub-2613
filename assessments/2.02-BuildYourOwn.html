2.02 · Build Your Own Website

Same Bootstrap skills as the clone — but this time the design decisions are yours. A real subject, four pages, portfolio-ready.

The rules

  • A real subject: yourself, a real business, or a club you belong to
  • About 4 pages, with a working nav on every one
  • Bootstrap 5 via CDN, your own style.css loaded after it
  • Real content and real images — no lorem ipsum in a submission
  • Validate, run WAVE, and test on an actual phone before you submit

Deliverable

Zip your project folder (delete README and .gitignore first) and upload to Study Hub → Subject 2 → Activities → Build Your Own Website. Your own GitHub repo is optional but encouraged.
